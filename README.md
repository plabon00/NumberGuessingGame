### **🎮 Number Guessing Game – Release v1.0**
Welcome to the official release of the **Number Guessing Game !**
This is a simple console-based game where the player attempts to guess a randomly generated number within a given range.

**### 📦 Download**
⬇️ **Download the JAR** file from the **Assets** section below.

Example: `NumberGuessingGame-v1.0.jar`

![Screenshot from 2025-05-17 16-50-30](https://github.com/user-attachments/assets/1306150a-b542-4715-8de4-3a85b88315f1)

**🚀 How to Run the Game**

**🐧 For Ubuntu/Linux:**

Open your terminal.

Navigate to the directory where you downloaded the .jar file:

`cd /path/to/downloads`

**Run the game with:**

`java -jar NumberGuessingGame-v1.0.jar`


**🪟 For Windows:**

Open Command Prompt (cmd).

Navigate to the folder where the .jar file is downloaded:

`cd C:\Path\To\Downloads`

**Run the game using:**

`java -jar NumberGuessingGame-v1.0.jar`

✅ Make sure you have Java installed on your system. You can verify with:

`java -version`

📌 **Notes**
No installation required.
The game runs entirely in the terminal/console.
Supports Java 8 and above.

Feel free to open issues or contribute if you'd like to improve the game!
Happy guessing! 🎉
